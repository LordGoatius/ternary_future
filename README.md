# The Next Generation

A series of experiments meant to speed up and improve the architecture of the next ternary virtual machine.

## Ternary
- New and improved ternary arithmetic. Much, much faster. Orders of magnitude faster.
- More arithmetic `impl`s.
- Cons: Requires nightly and const generics... it doesn't use anything absurdly crazy, and will be transitioned into the soonest available stable featureset that covers all basic needs.

## Memory Devices
- Dynamic memory device behavior for RAM, ROM, and MMIO
